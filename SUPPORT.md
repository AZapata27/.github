# Getting help

- **Questions and ideas:** open a GitHub Discussion in the repository when Discussions are
  enabled; otherwise open an issue with the feature request form.
- **Bugs:** open an issue with the bug report form, including the version and steps to
  reproduce.
- **Security vulnerabilities:** follow the [security policy](SECURITY.md); never post them
  publicly.

These are personal open-source projects maintained on a best-effort basis: there is no
support SLA and no guaranteed response time outside the security policy.
